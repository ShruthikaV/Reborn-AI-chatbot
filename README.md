# 💬 Reborn AI Chatbot – Addiction Recovery Assistant

**Reborn AI Chatbot** is a personalized, empathetic conversational agent built using Streamlit and Google’s Gemini API. It helps individuals facing addiction by answering queries, providing coping strategies, and offering guidance — all while maintaining anonymity and compassion.

---

## 🌟 Features

- 🔹 **Conversational AI** using Gemini (Gemini 1.5 Flash)
- 🔹 **Context-aware response generator**
- 🔹 **Custom avatars for user and bot**
- 🔹 **Dynamic CSS styling for a human-like feel**
- 🔹 **Real-time typing simulation**
- 🔹 **Privacy-first session history**
- 🔹 **Crisis detection prompts for self-harm or suicidal thoughts**

---


## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/ShruthikaV/Reborn-CHatbot.git
cd Reborn-CHatbot
```

### 2. To run the Chatbot
```
pip install -r requirements.txt #installing the dependencies
streamlit run main.py
```
